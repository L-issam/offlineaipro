# Banner Image pour Offline AI Pro

## 📋 Instructions pour créer banner.png

### Dimensions recommandées
- **Largeur** : 1024px
- **Hauteur** : 596px
- **Format** : PNG (transparence si possible)

### Design suggéré
- **Background** : Gradient bleu-violet (`linear-gradient(135deg, #667eea 0%, #764ba2 100%)`)
- **Texte principal** : "Offline AI Pro" en blanc, taille 48px
- **Sous-titre** : "Private AI Chat with Documents • 100% Offline" en blanc, taille 24px
- **Icône** : 🔒 ou 🧠 devant le titre

### Outils pour créer l'image
1. **Canva** (gratuit) : https://www.canva.com/
2. **Photoshop** ou **GIMP** (gratuit)
3. **Online tools** : https://www.bannerbear.com/ ou similaires

### Template HTML
Utilisez le fichier `create-banner.html` inclus dans ce dossier :
1. Ouvrez-le dans votre navigateur
2. Capture d'écran de la page (1024x596px)
3. Sauvegardez en PNG sous le nom `banner.png`

### Utilisation
Cette image sera utilisée pour :
- Les partages Facebook (Open Graph)
- Les tweets (Twitter Cards)
- Les previews dans les moteurs de recherche

### ⚠️ Important
- Le fichier doit être nommé exactement `banner.png`
- Il doit être uploadé à la racine du site GitHub Pages
- URL finale : `https://l-issam.github.io/offlineaipro/banner.png`
